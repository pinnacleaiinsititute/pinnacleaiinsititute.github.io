# 巔峰人工智能金融研究院 GitHub Pages 網站

部署網址：https://pinnacleaiinsititute.github.io/

## 上傳方式

1. 在 GitHub 建立名為 `pinnacleaiinsititute.github.io` 的公開倉庫。
2. 將本資料夾內的全部檔案與資料夾上傳到倉庫根目錄。
3. 把原始圖片放入 `images` 資料夾，檔名保持不變。
4. 在 Settings → Pages 將來源設為 Deploy from a branch，選擇 `main` 與 `/(root)`。
5. 發布後可將 `https://pinnacleaiinsititute.github.io/sitemap.xml` 提交至 Google Search Console。

## 必要圖片檔名

`1.png` 至 `13.png`、`IMG_1478.jpeg`、`LOGO -1.png`、`LOGO.png`。
